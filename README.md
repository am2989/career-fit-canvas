# Career Fit Canvas

Cria uma aplicação web simples chamada **CareerMatch AI**, para demonstrar uma ferramenta de comparação entre currículos e vagas de emprego.

### DESIGN
- Utiliza shadcn/ui e Tailwind CSS.
- Cores: azul claro (#8CCDF0), branco (#FFFFFF) e amarelo claro (#FFF1B8).
- Design moderno, minimalista e profissional.
- Interface em português de Portugal.
- Responsiva.
- Uma única página.
- Sem login, registo, backend ou APIs.

### FUNCIONALIDADE E INTERFACE

No topo, apresenta:

**CareerMatch AI**
"Adapte o seu currículo à vaga certa e destaque-se nos processos de recrutamento."

Cria dois cartões lado a lado:

**1. Descrição da vaga**
Uma caixa de texto grande para colar a descrição de uma oportunidade.

**2. O meu currículo**
Uma caixa de texto grande para colar o currículo atual.

Abaixo, coloca um botão azul:
"Analisar compatibilidade"

### RESULTADOS DE DEMONSTRAÇÃO

Ao clicar no botão, apresenta uma secção visual com:

- Compatibilidade: 85%.
- Palavras-chave encontradas: Excel, análise de dados, gestão, comunicação.
- Palavras-chave em falta: Power BI, SQL.
- Sugestões de melhoria do currículo.

Os resultados podem ser demonstrativos, sem necessidade de análise real complexa.

### CURRÍCULO OTIMIZADO

Apresenta um cartão com o título "O seu currículo otimizado para ATS".

Inclui uma pré-visualização de currículo profissional, organizada em:
- Perfil profissional.
- Competências.
- Experiência profissional.
- Formação académica.
- Idiomas.

Inclui um botão "Descarregar currículo PDF". Se a exportação real não for possível, apresenta uma versão preparada para impressão.

### AVISO

No final da página, apresenta:

"A CareerMatch AI melhora a apresentação das suas qualificações, mas nunca inventa experiências, competências ou certificações."

### IMPORTANTE

Prioriza exclusivamente o aspeto visual e a demonstração do conceito.

Não cries funcionalidades adicionais, páginas, dashboards, autenticação, integrações ou sistemas complexos.

Utiliza conteúdo de demonstração pré-preenchido para que seja possível visualizar imediatamente o funcionamento da aplicação.

**Cria diretamente o protótipo numa única página, simples e pronto para apresentar num desafio de aprendizagem.**
